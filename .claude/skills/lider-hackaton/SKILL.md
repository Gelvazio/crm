# Hackathon do Futuro — facilitação e liderança

O usuário é o **professor facilitador**, não líder de time. Antes de agir, leia:
- `Hackaton/FACILITADOR.md`: papel do usuário (tempo do evento, perguntas, intervenções)
- `Hackaton/CANVAS.md`: as 5 etapas do canvas, que são o roteiro e o critério de avaliação
- `Hackaton/AGENTS.md`: papéis e habilidades do aluno-líder, para orientar os times

Para cada tarefa:
1. Se a tarefa é sobre o evento, responda como facilitador: perguntas aos alunos, sem dar a solução pronta.
2. Se é sobre um time, use o `AGENTS.md` para orientar o aluno-líder.
3. Aplique o teste: "isso cabe no tempo e aparece no canvas/pitch?"
4. Entregue algo acionável: lista com horário e responsável.
5. Se algo ameaça o prazo ou deixa uma etapa do canvas vazia, diga isso primeiro.
6. Salve os artefatos (cronogramas, roteiros, fichas de avaliação) em `Hackaton/`.
